# What Customers Never Tell Your KPI Dashboard

Every morning, thousands of engineers open the same dashboards.

* Accessibility.
* Retainability.
* Mobility.
* Throughput.
* PRB utilization.

These KPIs tell us how the network is performing.
But they don't always tell us how customers are feeling.
I've worked on networks where every KPI was comfortably within target...
...yet customer complaints kept increasing.
I've also seen networks with less-than-perfect KPIs where users were perfectly satisfied.
At first, this seems contradictory.
But it really isn't.
Because customers don't experience KPIs.
They experience moments.
The video call that freezes during an important meeting.
The navigation app that stops updating while driving.
The payment that fails because the data session briefly dropped.
The call that disconnects just before saying goodbye.
None of these experiences starts with someone thinking:
"The retainability KPI increased by 0.3% today."
Customers simply conclude:
"The network isn't reliable."

That's why I've learned to treat KPIs as indicators—not as the final verdict.
When a customer reports poor service, my first question isn't:
"Which KPI is out of threshold?"
It's:
"What was the customer trying to do?"
Understanding the context completely changes the investigation.

The same throughput value can be acceptable for web browsing but unacceptable for a live video conference.
The same latency may go unnoticed during file downloads but become critical during cloud gaming or voice services.
Technology measures performance.
Customers measure experience.
The challenge for every RAN engineer is connecting those two worlds.
This is where AI and Network Automation can make a real difference.
Not simply by analyzing more KPIs.

But by correlating network behavior with the services customers are actually using and the experience they're trying to achieve.
Because the ultimate goal isn't to build a network with perfect dashboards.
It's to build a network where customers never feel the need to complain.
Sometimes, the most important KPI...
...is the one your dashboard doesn't show.

**If you could add one metric that better represents the real customer experience, what would it be?**
